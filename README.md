# 商品销售数据分析

## 项目背景
本项目旨在分析某店铺 2022 年全年的商品销售数据，通过数据可视化找出销售趋势，为店铺运营提供决策支持。

## 数据来源
- **信息表**：包含商品大类、小类、名称、编号及销售价。
- **销售数据表**：包含订单日期、订单编号、商品编号及订单数量。

## 分析方法
1. 使用 Pandas 合并两张数据表（通过“商品编号”关联）。
2. 计算每笔订单的销售金额（销售价 × 数量）。
3. 按月汇总总销售额，绘制折线图观察年度趋势。
4. 按商品大类分组，绘制月度柱状图对比不同品类表现。
5. 按商品小类汇总，绘制年度销售额柱状图找出畅销品类。

## 分析结论（根据你实际生成的图表填写）
- 全年销售在 6-10 月达到高峰，可能与夏季运动需求增加有关。
- 运动上装贡献了最大的销售额，其中“短袖”类表现突出。
- 运动配饰类销售额相对平稳，发带类产品受欢迎。
